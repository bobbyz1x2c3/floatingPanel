# NemuFloat · 悬浮卡片

一块**磨砂玻璃背景 + 新拟态控件**的悬浮卡片面板，用四象限（紧急 / 重要）组织事情。一份代码同时产出 Windows / macOS / Linux 原生悬浮窗，也能直接在浏览器和移动端运行。

![风格](https://img.shields.io/badge/style-glassmorphism%20%2B%20neumorphism-6d8bff) ![平台](https://img.shields.io/badge/platform-Windows%20%7C%20macOS%20%7C%20Linux%20%7C%20Web%20%7C%20Mobile-46c2a0)

## 风格约定

混搭的关键是**分层**：大面积的容器用玻璃，能按的小控件用新拟态。

| 层 | 手法 | 实现 |
| --- | --- | --- |
| 面板 / 抽屉 / 提示条 | 磨砂玻璃 | 半透明填充 + `backdrop-filter` + 1px 高明度描边 + 环境投影 |
| 卡片 | 玻璃基底 + 抬升感 | 半透明填充 + 柔和环境阴影（不再用大面积白色外发光） |
| 按钮 / 开关 / 滑杆 / 输入框 | 新拟态 | 同色半透明底 + 双阴影（暗右下 / 亮左上），按下时切换为内阴影 |

玻璃要“看得出来”，就必须有可被模糊的东西，这一点桌面端和浏览器端完全不同：

| 端 | 来源 | 说明 |
| --- | --- | --- |
| 浏览器 | CSS `backdrop-filter` | 面板背后由 `--glass-aura-*` 绘制柔光晕，`backdrop-filter` 负责把它磨砂化 |
| 桌面端 | 窗口透明 + CSS 半透明填充 | 直接用半透明填充透出**真实桌面**（清晰的玻璃，不是模糊的） |

桌面端**刻意没有**打开系统级材质（`windowEffects` 的 acrylic）：Windows 会在窗口失去焦点时把它退化成一块不透明的纯色，
于是「没选中这个窗口」的时候面板反而更实、而且聚焦 / 失焦两种观感不一致。
不用系统材质之后，面板就是纯 CSS 的半透明填充，聚焦与否长得一样，桌面也能如实地透出来。

桌面端还会去掉外壳留白（`--shell-pad: 0`）并把面板圆角交给系统：Windows 11 会为无边框窗口绘制圆角与投影。

## 技术栈

- **Tauri 2**：Rust 外壳，输出体积小、支持桌面 + 移动端
- **React 19 + TypeScript**：界面与状态
- **Vite 7**：开发与构建
- **零运行时 UI 依赖**：所有控件、图标、阴影都是手写 CSS / SVG

### 字体

界面字体是 **得意黑（Smiley Sans，SIL OFL 1.1）**，放在 `fonts/`，只留了一份 `SmileySans-Oblique.woff2`：
Tauri 用的是 Chromium，现代浏览器也都吃 woff2，原来的 otf / ttf 是重复的，已经删掉（省 5 MB）。
换字体只要替换这个文件 + 改 `src/styles/tokens.css` 顶部的 `@font-face` 和 `app.css` 里的 `font-family`。

### 图标

应用图标和托盘上的大小番茄都是**生图出来的透明底图**（`assets/`，用 `codex-image2` 那个 skill 生成的：
新拟物 / 黏土质感的单个物体、纯白背景提示词直接得到带 alpha 的 PNG）：

| 文件 | 用在哪 |
| --- | --- |
| `assets/app-icon.png` | 应用图标源图，`npm run icon` 由它生成 `src-tauri/icons/` 全套（ico / icns / 各尺寸 png） |
| `assets/tomato-small.png` | 托盘上的「小番茄」 |
| `assets/tomato-big.png` | 托盘上的「大番茄」 |

生成完用 `work/cutout.py` 按 alpha 裁到主体、补成正方形再缩到目标尺寸（生图返回的是 1254×1254）。

## 四象限

画布被分成四块，卡片停在哪个象限由**卡片中心点**决定，跨过分界线会自动换象限并换上对应的强调色：

| 位置 | 象限 | 强调色 |
| --- | --- | --- |
| 右上 | 紧急 · 重要（立刻去做） | 玫瑰 |
| 右下 | 紧急 · 不重要（交给别人） | 琥珀 |
| 左上 | 重要 · 不紧急（计划去做） | 天蓝 |
| 左下 | 不重要 · 不紧急（有空再说） | 石墨 |

四个象限**跟着窗口走**：每格恒等于画布可视区的一半，窗口拉大拉小、缩放、换屏幕都会自动重算，卡片本身留在原处（画布不够大时出现滚动条）。窗口再小也不会把某一格挤没，有 320 × 250 的最小尺寸兜底。

「整理」会把每张卡片放回它所属的象限，并且**按「从上往下、从左往右」的顺序找第一个放得下的位置**——
被删掉的卡片留下的空当会被后面的卡片补上，同一行能并排就并排，而不是固定堆成一列。
整张卡片必须落在自己那一格里面（不跨过分界线）；真装不下了才排到格子下面，
而且溢出之后依然会左右并排，也不会压到下面那一格的卡片上（所有卡片共用一份「已占位置」）。
顺序只跟卡片的创建时间有关，所以连按几次「整理」结果都一样。

空白处双击会在双击所在的象限放下新卡片，位置同样是这一格里第一个放得下的空位；
从归档恢复卡片也一样。

## 交互

- 拖动卡片**标题栏**移动（在标题上直接拖也能拖动整张卡；只点不拖就是正常落光标）
- **卡片四周的边和角都能拉伸**：没有看得见的手柄，鼠标贴到边缘时光标会变成对应的缩放箭头，上 / 下 / 左 / 右和四个角一共 8 个方向
- **在空白处双击**就能新建卡片（没有「新建」按钮），卡片落在双击所在的象限
- 卡片右上角是三个图标按钮，从左到右：**删除、收起 / 展开、完成**。「完成」比其他两个大一号、带强调色的高光和投影，一眼能认出来
- 点「完成」的瞬间就响完成音效，同时播一段收起动效，然后这张卡片被归档
- 卡片头上的时间戳是**最后更新时间**（`4m` / `3hrs` 这种短写），鼠标悬停能看到完整时间
- 画板支持滚动；卡片可以拖到画布任意位置
- 内容自动写入 `localStorage`（键名 `nemu-float.board.v1`）

顶栏只有一行，用三列网格排布：左边是品牌，**搜索框固定在正中间**，右边是整理、全部收起、主题、归档（带数量徽标）、设置，以及桌面端的置顶 / 最小化 / 最大化 / 关闭。

左侧那列和右侧那列一样宽，所以搜索框是相对整个菜单栏居中，而不是相对剩下的空隙居中；右边按钮增减都不会把搜索框挤歪。搜索框的宽度是「窗口宽 − 两侧各自要占的宽度 × 2 − 余量」，所以窗口变窄时它会先自己收窄，绝不会被右侧那组按钮压住。

窗口继续变窄会依次：收掉「归档」两个字（数量徽标保留）→ 收掉分隔线 → 当两侧按钮的固有宽度已经超过「各占一半」能分给它们的份额时（约 1000px 以下），顶栏换成普通 flex 排布，搜索框吃掉剩下的空间。此时它不再严格居中（那么窄的窗口里数学上也做不到），但保证谁都不压谁、每个按钮都点得到。

层级上，卡片被关在自己的堆叠上下文里（`.board-canvas` 的 `isolation: isolate`），所以卡片的 z-index 再大也只在自己那层比大小，永远盖不到抽屉和提示条上；顶栏 / 抽屉 / 提示条用 `--z-topbar` / `--z-drawer` / `--z-toast` 三个变量统一排序。

快捷键：`Ctrl/Cmd + N` 新建 · `Ctrl/Cmd + F` 搜索 · `Ctrl/Cmd + ,` 设置 · `Esc` 收起抽屉

## 归档

顶栏的「归档」按钮外面挂着已归档的数量。点开后能看到所有归档卡片、它们原本的象限、附件数量，以及**归档时间**（绝对时间 + 相对时间），可以单张恢复、单张删除或清空归档。归档区最多保留 300 张。

## 附件

卡片支持三种内容来源，全部会随卡片一起保存：

| 操作 | 结果 |
| --- | --- |
| 在卡片里 `Ctrl/Cmd + V` 粘贴截图 | 变成内嵌图片（自动缩放后再存） |
| 把图片拖进卡片 | 变成内嵌图片 |
| 把图片 / 文件 / 文件夹拖到空白处 | 顺手新建一张卡片，把拖进来的东西挂上去 |
| 把文件或文件夹拖进卡片 | 变成一条链接（文件夹名字后面带 `/` 方便区分） |
| 拖到**菜单栏或窗口任意位置** | 一样会新建卡片，位置按左右分到对应象限里排，不会跑到窗口外面 |

- 正文里出现的网址会被自动识别成链接条
- **按住 `Ctrl`（macOS 为 `⌘`）点击**文件链接或网址才会打开；普通点击只给一句提示，避免编辑时误触
- 图片附件**点一下会开一个独立窗口**放大查看，主面板该拖该改都不受影响
- 单张卡片最多 12 个附件

> 浏览器模式拿不到本地文件的真实路径，拖进来的非图片文件会用会话内的 `blob:` 地址，刷新后失效；桌面端拿到的是真实路径，`Ctrl + 点击`交给系统默认程序打开。

## 图片预览窗

预览窗是一个**独立的系统窗口**（浏览器端是弹出窗口），可以拖到屏幕另一侧，一边看一边改面板。窗口内提供：

| 能力 | 说明 |
| --- | --- |
| 单条标题栏 | 整个窗口只有标题栏这一条：标注工具、缩放、窗口按钮全在里面，图片区不再被工具条占走一行 |
| 临时标注 | 铅笔、矩形、圆形、箭头四种工具，四色可选；支持撤销上一笔和清空 |
| 标注可收起 | 点标注组最左边的折角按钮就把整组收掉（收起后左键也变成平移，就是一块纯看图，标注本身留在画面上不消失） |
| 缩放 | **滚轮直接缩放**，以光标为中心（不用按 Ctrl）；按钮在标题栏右侧、窗口按钮左边（缩小 / 百分比 / 放大 / 适应窗口），点百分比回到 100% |
| 平移 | 放大之后按住**右键**拖动即可平移，中键或空格 + 左键同样可以；按 Ctrl 滚轮、按 Shift 滚轮则交还给滚动条 |
| 窗口 | **整条标题栏都能拖动窗口**（文件名留白、左侧内边距、按钮缝隙都算），右上角置顶开关、最小化、最大化 / 还原、关闭 |

标题栏要塞下这么多东西，所以窗口变窄时会依次收掉：尺寸（≤980px）→ 颜色（≤860px）→ 撤销/清空（≤820px）→
标注工具按钮（≤700px，只剩折角按钮）→ 适应窗口 + 按钮缩一档（≤620px）。窗口按钮和缩放百分比始终在。

标注是**临时的**：只画在预览窗的图层上，不会写回卡片，关掉窗口就没了。标注坐标存的是图片像素坐标，所以缩放之后线还是贴着原来画的地方。

窗口之间靠 `localStorage` 传递这一张图（`nemu-float.preview.<id>`，只保留最近一份），因此预览窗和主面板不共享内存，互不阻塞。

> 主面板顶栏和预览窗标题栏都用 `data-tauri-drag-region="deep"`：容器里凡是不落在按钮 / 输入框上的地方都能拖动窗口，不用逐个元素去标。双击这两条栏会最大化 / 还原窗口，和无边框窗口的常规习惯一致。

## 命令行（nemu）

除了鼠标，卡片还可以用命令行读写——给脚本和 AI agent 用。构建一次：

```bash
npm run cli:build     # 产物：src-tauri/target/release/nemu(.exe)
```

**装应用的时候会一起装上**：`npm run desktop:build` 会先把 `nemu` 拷进 `src-tauri/bin/`
（`bundle.resources` 引用的就是它），安装包会把它装到应用目录下：

| 平台 | 安装后的位置 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\NemuFloat\bin\nemu.exe` |
| macOS | `/Applications/NemuFloat.app/Contents/Resources/bin/nemu` |
| Linux | `/usr/lib/NemuFloat/bin/nemu` |

所以 agent 不用额外装东西，直接用上面这个路径（或者自己加进 PATH）就能读写卡片。

```bash
nemu list                       # 列出卡片
nemu list --quadrant do         # 只看「紧急 · 重要」
nemu search 周报                # 按标题 / 正文 / 附件名搜
nemu show '#1'                  # 看第 1 张的完整内容
nemu add --title "写周报" --body "整理本周进展" --quadrant schedule
nemu add --title "看这个 issue" --url "https://example.com/i/1"
nemu add --title "设计稿" --attach "D:\design\home.png"
nemu set '#2' --append "补一句：下周一交"
nemu done '#2'                  # 完成并归档
nemu archived / restore '#1' / rm '#2' / clear-archive
nemu board                      # 各象限分布 + 状态文件路径
```

选择器支持完整 id、id 前缀（`a7226231`）或 `#序号`；所有命令都能加 `--json` 给机器读。

**它是怎么和界面接上的**：状态不再只存在 WebView 的 `localStorage` 里，桌面端会把它同步到
`%APPDATA%\app.nemufloat.desktop\board.json`（macOS / Linux 见 `nemu path`）。界面每次改动写这个文件，
并且每 1.2 秒比对一次文件的修改时间——所以 CLI 写完，窗口里 1~2 秒就会自己出现；app 没开着的时候 CLI 也能直接写，
下次启动就能看到。写入用「临时文件 + 重命名」，两边同时写也不会读到半截内容。

浏览器模式没有这个文件，只能用界面本身。

## 给 agent 用的 skill

仓库里带了一份 skill：`skills/nemufloat-cards/SKILL.md`，把上面的命令、象限含义和常用流程写成了 agent 能直接照做的一页说明。
把它放进 `~/.codex/skills/nemufloat-cards/`（本机已经装了一份）之后，让 agent「把这几件事记到悬浮卡片上」它就知道该怎么调 `nemu`。

## 设置项

主题（浅色 / 深色 / 跟随系统）、强调色、**背景透明度**、颗粒质感、磨砂强度、对齐网格、显示网格、完成音效、**音频响应**、**番茄钟时长**、窗口置顶、**自动检查更新**，以及整理布局 / 收起全部 / 恢复示例 / 清空卡片。

番茄钟和托盘那一组里还能配：小/大番茄各多少分钟、**托盘显不显示番茄**、**显不显示工具**、
**托盘贴左边 / 居中 / 贴右边**，以及托盘上要挂哪些快捷方式。

「背景透明度」只改面板底色的 alpha（`--glass-fill*`，由 settings 换算后写在根节点上），
**卡片和文字不受影响**，所以拉到很透也照样看得清；默认 58% 透明（alpha 0.42），0% 是全不透明、85% 是几乎全透。
想改默认值见 `src/styles/tokens.css` 里的 `--glass-fill*`。

窗口行为相关项在浏览器模式下会自动禁用并提示“仅桌面端可用”。

## 音频响应

打开之后，**面板背景的底部**会浮起一层跟着**电脑正在播放的声音**跳动的频谱：55 根柱子（28 个频段左右镜像，
低频在两边、高频在中间）从底边升起来，外加一层跟着整体响度呼吸的强调色光晕。
它垫在所有卡片下面、跟着面板一起圆角裁切，不挡点击（`pointer-events: none`），所以卡片、抽屉、提示条都在它上面。

它抓的是系统播放通道：Windows 上用 WASAPI 的 loopback 拿默认播放设备的混音数据（就是喇叭里正在响的东西），
在 Rust 里降采样到 8kHz、每 30 毫秒做一次 Goertzel 频段分析，只把 28 个 0~1 的数值发给界面。
**音频数据不会离开进程，也不写入磁盘**，界面上拿到的只是数值；关掉开关或退出应用，捕获线程立刻停。

目前只有 Windows 有回环捕获，其它平台这一项会禁用。占用的 CPU 基本可以忽略（每秒约 100 万次乘加）。

## 自动更新

用的是 Tauri 官方的 updater 插件，**已经启用**：`src-tauri/tauri.conf.json` 里填好了公钥、打开了
`bundle.createUpdaterArtifacts`，release 流程用仓库 secret `TAURI_SIGNING_PRIVATE_KEY` 给安装包签名。

1. 启动 4 秒后（且「自动检查更新」开着）自动查一次，也可以随时在设置里点「检查更新」；
2. 有新版本，设置里会显示「发现新版本 x.y.z」并冒出「下载并安装」，设置按钮上同时亮一个小圆点；
3. 点下去带进度下载、安装（Windows 走 passive 静默安装），装完调用 `relaunch()` 重启。

更新清单地址写在 `plugins.updater.endpoints`，指向本仓库 Release 里的 `latest.json`：

```json
{
```

Tauri 打包时会给安装包写一份 `.sig` 签名，release 流程的 `manifest` 步骤会把四个平台的产物下载回来，
用 `scripts/make-updater-manifest.mjs` 汇成一份正式的 `latest.json`（`platforms` 取并集、`notes` 用当次
Release 说明）。必需平台缺产物或签名会让这一步失败，不会发布一份悄悄少平台的清单。
签名校验不过、清单 404、网络不通都会在设置里落成一句人话（「还没配置更新公钥」/「更新清单还没发布」/
「网络不通，稍后再试」），不会静默失败。

自己发一个新版本：

```bash
# 只做一次：生成密钥对，私钥自己收好（本机放在 ~/.nemufloat/），公钥填进 tauri.conf.json
npx tauri signer generate -w ~/.nemufloat/nemufloat.key
# 把私钥内容写进仓库 secret TAURI_SIGNING_PRIVATE_KEY，然后：

# 每次发版：两处版本号一起改 -> 提交 -> 打 tag -> 推 tag，剩下的交给 .github/workflows/release.yml
```

## 发布页

`docs/` 是一张独立的发布页（纯静态、零依赖，视觉沿用 app 里的玻璃 + 新拟态）：
版本号、按平台给下载按钮、更新说明、历史版本列表、从源码构建的步骤、CLI 用法。

它由两条 workflow 带起来：

| workflow | 什么时候跑 | 做什么 |
| --- | --- | --- |
| `.github/workflows/release.yml` | 推 `v*` 标签（或手动指定 tag） | 先建 Release，再按平台矩阵并行打包，把安装包和更新产物（Windows NSIS+MSI / macOS 双架构 app+dmg / Linux AppImage+deb）连同 `.sig` 签名传成同一个版本的附件，最后把各平台清单合并成一份 `latest.json` |
| `.github/workflows/pages.yml` | `docs/` 有改动、或手动触发、或 Release 完成后自动调一次 | 用 token 把 Release 列表取成 `docs/releases.json`，再把 `docs/` 发到 GitHub Pages |

版本清单是**部署时用 token 生成**的，所以私有仓库也能正常显示，页面自己不需要任何凭证；
本地直接打开 `docs/index.html` 时读不到清单，会退回显示「还没有可下载的版本」和自建步骤。

开启 Pages 需要仓库具备 Pages 权限：公开仓库可以，私有仓库需要 GitHub Pro 及以上。
workflow 里带了 `enablement: true`，第一次跑会自动把 Pages 打开。

本地看效果：

```bash
python -m http.server 4180 --directory docs   # 然后打开 http://127.0.0.1:4180/
```

界面上的动效都集中在 `src/styles/app.css`，并且全部尊重系统的「减少动态效果」（`prefers-reduced-motion`）：

| 位置 | 效果 |
| --- | --- |
| 卡片 | 首屏依次落下来（带 26ms 递增延迟）；**双击 / 拖入新建的卡片从中心展开**（`is-new`，0.78 → 1.03 → 1）；删除时先缩小淡出再消失；跨象限时强调色渐变过去 |
| 收起 / 展开 | 卡片高度在 260ms 里过渡（只在切换那一下挂 `is-toggling`，平时高度是跟手拖的，不能有过渡） |
| 整理 | 卡片滑到新位置（`is-moving`，380ms），而不是瞬移 |
| 对齐网格 | 拖动时每次吸附补 60ms 的位移过渡，看着像被格子吸过去 |
| 番茄钟 | 拖到卡片上时卡片亮起呼吸圈，面板背景上滚动一个大号倒计时；结束时响钟 + 中央弹「时间到」，卡片底边留下小方块标记 |
| 完成卡片 | 屏幕中央弹一发很大的半透明「已完成」（200px、峰值不透明度 0.62），像游戏里的完成提示 |
| 归档 | 缩一下 + 一圈强调色扩散 + 淡出，同时响完成音效 |
| 抽屉 | 从右上角淡入并轻微下移 |
| 提示条 | 从下方浮入，到点先淡出再移除；开着频谱时自动抬高，不和频谱打架 |
| 拖放 | 悬停的卡片描边脉动 |
| 频谱 | 面板背景里每根柱子独立缩放，涨得快落得慢；底部光晕按整体响度呼吸 |

## 目录结构

```
src/
  components/      界面组件（卡片、画板、顶栏、归档抽屉、设置抽屉、图片预览窗、控件库、图标）
  lib/             状态机（store.ts）、持久化、状态文件桥接（boardFile.ts）、平台桥接（platform.ts）、预览传参（preview.ts）、附件、链接识别、图片压缩、格式化、完成音效（sound.ts）
  styles/          tokens.css（设计变量）/ neumorphism.css（控件库）/ app.css（主面板布局）/ preview.css（预览窗）
src-tauri/         Rust 外壳、窗口配置、权限、图标；board.rs 是界面和 CLI 共用的状态文件读写
src-tauri/cli/     命令行工具 nemu（单独一个 crate，免得打包时和 app 二进制混在一起）
skills/            给 agent 用的 skill（nemufloat-cards）
scripts/           应用图标生成脚本
```

设计变量集中在 `src/styles/tokens.css`：改 `--glass-*` 调玻璃，改 `--nm-*` 调新拟态。

## 番茄钟

界面下方浮着一块**磨砂玻璃面板**：填充用的是和主面板同一个 `--glass-fill`，靠 `backdrop-filter`
把背后的东西磨砂化，里面排一排**圆形的新拟态按钮**——两颗番茄、自定义工具、末尾一个「＋」（跳去设置），
计时中时末尾多出一个取消按钮；剩余时间只显示在面板背景上。面板宽度、位置和内容都能在设置里配（见下）。

### 托盘的快捷方式

番茄面板右侧可以挂自己的快捷方式（设置 → 托盘工具 → 加一个），三种类型：

| 类型 | 说明 |
| --- | --- |
| 内置动作 | 整理布局 / 打开归档 / 打开设置 / 新建卡片 / 收起全部 |
| 打开链接 / 文件 | 交给系统默认程序打开（网址、文件夹、文件都行） |
| 执行命令 | 直接交给系统执行（Windows 走 `cmd /C`，其它平台走 `sh -c`）。**只填自己信得过的命令** |

托盘最右边那个「＋」就是跳到设置里的这块。快捷方式存在 `settings.trayTools` 里，最多 12 个，跟着存档走。

界面下方浮着一条番茄面板，两颗番茄可以**直接拖到某张卡片上**开始计时：

| 番茄 | 默认时长 | 说明 |
| --- | --- | --- |
| 小番茄 | 15 分钟 | 设置里可以改（5~60 分钟，步进 5） |
| 大番茄 | 30 分钟 | 设置里可以改（5~120 分钟，步进 5） |

- 拖上去之后那张卡片会**高亮**（番茄色呼吸圈），面板背景上出现一个**很大的半透明倒计时**（`12:11` 那种），
  下方面板只显示「取消」按钮，托盘里不重复显示时间，中途随时可以取消。
- 倒计时结束：响一声钟（比完成音更低更长）+ 中央弹一发「时间到」，然后在卡片**底边右侧**留下一颗小方块标记。
  打完几颗就是几个方块（超过 6 个显示 `+n`）。
- **番茄钟不改变卡片的完成 / 归档状态**，只是加个标记；标记数存在卡片的 `pomodoros` 上，跟着存档走（CLI 也能读）。
- 同一时间只跑一个番茄钟；再拖一颗上来会换成新的那个。

### 专注模式

托盘上的聚焦按钮会把所有卡片收拢成一叠，只突出当前卡片，窗口也随之缩到当前卡片加底部控制条的大小。控制条可以切换置顶、上一张 / 下一张卡片、直接启动小 / 大番茄钟或退出；番茄倒计时和音频响应显示在当前卡片的文本框背景中。失去窗口焦点两秒后控制条自动收起，重新聚焦时滑出。
