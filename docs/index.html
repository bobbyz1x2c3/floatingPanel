它有什么

四象限画布

卡片拖过分界线就自动换象限、跟着象限换颜色。四条边都能拖，想多大就多大。

整理会找空位

点一下「整理」，卡片自动排整齐：删卡留下的空当会被补上，能并排的就并排。

归档与附件

做完的卡片点一下就归档，什么时候完成的一目了然。截图、图片、文件、链接都能贴进卡片。

独立图片预览窗

点缩略图单独开一个窗口，铅笔、方框、圆圈、箭头随手标注，滚轮缩放，还能钉在最上层。

番茄钟与专注模式

把番茄拖到卡片上开始倒计时，时间到响铃提醒。专注模式把卡片收成一叠，只看你正在做的那张。

背景频谱

打开后，面板背景会跟着声音变化，画面更有节奏感。

命令行协作

用 nemu 添加、查找和完成卡片，适合把整理工作交给 agent。

自动更新

桌面端启动时自动检查新版本，设置里也可以手动检查，下载安装一步到位。
